# 流入元記録

**書き方**: 問い合わせが来たら、下の表に1行足すだけ。1件30秒。
流入元は「カーセンサー / グーネット / ジモティ / メルカリ / LINE / TikTok / Instagram / X / 電話 / 紹介」から選ぶ。
