営業応募オートパイロット v12（報酬・URLの読み取り精度向上）

【重要】このフォルダは消さないでください。
Chromeがこのフォルダを直接読んで動いています。

■ 入れ方

  ※ 前の版が入っている場合は、先に chrome://extensions で
    古いほうの「削除」を押してください（上書きにはなりません）。

1. Chromeのアドレスバーに  chrome://extensions  と入力してEnter
2. 画面右上の「デベロッパーモード」をオン
3. 左上の「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（manifest.json が入っているフォルダ）を選んで
  「フォルダーの選択」
5. 「営業応募オートパイロット」がリストに出れば完了

プロフィール（氏名・メール・電話・住所・稼働条件・実績）は
すでに全部入っています。設定作業はありません。

■ 使い方

  拡張機能アイコン →「🔍 条件に合う案件を探して開く」

  ★ 開いたタブは、もう応募文が出来上がっています。
    読んで、直したいところだけ直して、送ってください。

裏で複業クラウド・ランサーズ・Indeedを順に回り、一覧を読み、
詳細ページの本文まで読みに行って判定し、終わったタブを閉じます。
最後に「マスト条件を満たした案件だけ」がタブで開きます。

進捗欄に「◯◯を見ています…」と出れば動いています。
巡回には数分かかります。ポップアップは閉じても大丈夫です。

■ 開いた案件で

  応募文はすでに出来ています。声に出して1回読む →「応募ページへ」
  →「③ フォームに入れる」→ 自分で送信 →「応募済みにする」

  ※ 送信ボタンは自動では押しません。
  ※ 気に入らなければ「別の言い回しで」で作り直せます。

■ 募集要項を読んでから書きます

  発注者が募集文に書いている指示を読み取って、応募文に反映します。

  ・「応募時に以下を記載してください」→ 指定項目に1つずつ答えます
   （お名前・年齢・稼働可能時間・営業経験・志望動機・通信環境・
    使用ツール・希望単価・保有資格・顔出しの可否 などに対応）
  ・「冒頭に『◯◯』と記載してください」→ 合言葉を必ず先頭に入れます
   （これを守らないと、読まれずに落とされます）
  ・「400文字以内で」→ その字数に収めます
   （削るときも、会社の言葉・熱量・稼働条件・締めは必ず残します）
  ・会社名と、会社が大切にしている言葉 → その言葉を借りて一文を書きます

  パネルの「募集要項から読み取ったこと」に、何を読み取ったかが出ます。
  答えられない項目（年齢など）は【要記入】で残るので、そこだけ埋めてください。
  設定画面に「年齢」「希望単価」「顔出しの可否」「保有資格」を入れておくと、
  次からは自動で埋まります。

■ 同じ案件は二度と出てきません

  案件は必ずこの6つのどれかの状態を持ちます。

   候補     … 条件を満たす。まだ何もしていない → タブで開く対象
   書きかけ … 応募文ができている。まだ送っていない
   応募済み … 送った。★二度と出てきません
   見送り   … 自分で見送った。★二度と出てきません
   対象外   … 条件に合わない。★二度と出てきません
   未判定   … 集めたばかり

  ・一度タブで開いた案件は、二度と開き直しません
  ・応募済み・見送り・対象外は、何度巡回しても出てきません
  ・すでに調べた案件は詳細を調べ直しません（巡回が速くなります）
  ・マスト条件を変えても、書きかけ・応募済み・見送りは触りません
   （自分で判断した結果を、機械が勝手に戻さないため）
  ・応募済みにした案件を候補に戻すことはできません（二重応募の防止）

  ポップアップ上部に「候補 / 書きかけ / 応募済み / 見送り / 対象外」の
  件数が出ます。タブで切り替えて中身を見られます。

■ どこまで探すか

  ・1ページ目で足りなければ、3ページ目まで辿ります
  ・条件に合う案件が指定件数（初期値10件）見つかったら、そこで切り上げます
  ・すでに知っている案件は飛ばすので、2回目以降の巡回は速くなります

  設定はポップアップで変えられます。

■ 案件を開いたあとの操作

   「✅ 応募した」… 応募済みにする（二度と出てこなくなります）
   「見送る」    … 見送りにする（二度と出てこなくなります）
   「別の言い回しで」… 応募文を作り直す
   「コピー」    … 応募文をコピー

■ マスト条件

▼ 絶対に届かないもの（設定に関わらず除外）
   BtoB／有形商材／アポイント自己獲得型／現場訪問が必須／
   子ども・学生向け／商材単価10万円以下／危険な案件／
   クラウドワークスの案件

▼ 募集文でこれが確認できたものだけ届く（初期設定・変更可）
   ☑ BtoC（個人向け）  ☑ 無形商材  ☑ アポイント譲渡型  ☑ オンライン完結
   ☐ 商材単価30万〜120万円  ☐ 一般成人向け

★「募集文に書いていない」ものは通しません。
  例えばアポイントの出所が書かれていない案件は、条件に反していなくても
  届きません（面接で確認するまで判断できないため）。

★「どちらとも取れる」ものも通しません。
  ・「個人と法人の両方に対応」→ 通さない（BtoBが混ざるため）
  ・「アポは支給しますが新規開拓もお願いします」→ 通さない
   （募集文からは"任意"か"必須"かを区別できないため）

★候補が0件のとき、画面に理由が出ます。

  例:
   集めた29件はすべて対象外でした。内訳はこうです。
   条件に反していたもの: 営業対象 12件、商材の種類 5件
   募集文で確認できなかったもの: アポイント譲渡型 24件、BtoC 18件
   →「アポイント譲渡型」のチェックを外すと 9件が候補になります。

  マスト条件のチェックの横にも「◯件が未確認／外すと+◯件」と出ます。
  どれを外せばいくつ増えるかを見てから決められます。

「対象外」タブで1件ずつ理由を確認できます。
CSVで書き出してClaudeに渡すと、読み取りの精度を上げられます。

■ 事前にやっておくこと

  複業クラウド（talent.aw-anotherworks.com）にログインしておいてください。
  ログインしていないと、そこだけ取得できず「時間切れ」になります。

■ ★実サイトでうまく動かないときは「診断」を使ってください

  Claudeは組織のネットワーク制限で、ランサーズ・Indeed・複業クラウドに
  直接アクセスできません（403で遮断されています）。
  そのため「実際のページで何がどこまで読めているか」が分かりません。

  そこで、ツール自身に報告させる機能を付けました。

   1. うまくいかないページ（案件一覧・詳細・応募フォームのどれでも）を開く
   2. 拡張機能アイコン →「🔧 このページを診断」
   3. 数秒待つ →「コピー」を押す
   4. Claudeにそのまま貼る

  出てくる内容:
   ・媒体とページ種別を正しく判定できているか
   ・案件を何件読み取れたか／タイトルが重複していないか
   ・詳細ページを取得できたか／本文を何字読めたか
   ・6つの条件をどう判定したか
   ・募集要項から何を読み取れたか（合言葉・指定項目・字数制限）
   ・応募フォームの入力欄・氏名欄・送信ボタンが見つかるか

  ★個人情報は一切含まれません（欄の「有無」だけで、中身は出しません）。
   そのまま貼って大丈夫です。

■ CSVは常に全件を書き出します（v11で修正）

  以前は今開いているタブの中身だけを書き出していたため、
  「候補」タブ（0件）を見たまま押すと空のCSVになる不具合がありました。
  今はどのタブを見ていても、集めた全件（候補・書きかけ・応募済み・
  対象外すべて）を書き出します。

■ JavaScriptで中身を読み込むサイトを自動で見分けます（v11で追加）

  複業クラウドのような、クリックしても中身がその場で切り替わるだけの
  サイト（JavaScriptで後から内容を読み込むタイプ）は、詳細ページを
  fetchで取りに行っても中身のない外枠しか取れません。

  これを2回検知したら、そのサイトへの詳細取得を自動でやめて、
  一覧のカードに書いてある短い説明だけで判定します。
  進捗ログに「詳細ページはJavaScriptで読み込まれるため取得できません
  でした」と出たら、それがこのサイトです。

  ★このタイプのサイトで正確に判定したいときは、気になる案件を
   実際に開いて「🔧 このページを診断」を使ってください
   （拡張機能は実際のブラウザの中で動くので、JavaScriptが実行された
   後の本物の中身を読めます。fetchだけの自動巡回とは違います）。

■ 報酬の読み取りを直しました（v12）

  「時給1,900円プロフィールだけでカンタン応募」のように、金額の
  すぐ後ろにボタンの文言まで巻き込んでしまう不具合がありました。
  金額（◯円・◯円〜◯円・◯万円など）が終わったところで正しく止まる
  ようにしました。「成果報酬」「応相談」のような金額の書いていない
  表記も、そのまま拾います。

■ IndeedのURLが壊れる不具合を直しました（v12）

  Indeedは案件を「?jk=英数字」という形のURLで区別しますが、
  詳細ページの取得に失敗した案件（BtoB等で除外された案件）では、
  このjkが欠けたリンク切れのURLがCSVや一覧に出ることがありました。
  常に正しいURLを組み立て直すようにしたので、どの案件も正しく
  開けます。

■ 困ったら（Claudeに伝えてください）

・候補が0件 → マスト条件を減らす／検索キーワードを増やす
・複業クラウドで取れない → ログインした状態で案件検索した画面のURL
・案件が拾えない → そのページのURL
・エラーが出る → chrome://extensions →「Service Worker」→ Console の赤い文字
