# 応募文の文体ガイド（AI感を消すためのルール）

このファイルは「琴音さんが書いたようにしか見えない文章」を作るための決まりごと。
`extension/core/phrases.js` を書き換えるときは必ずここを守る。

## 大前提

**上手い文章より、本人が書いた文章。**
発注者は毎日AIが書いた同じような応募文を10通読んでいる。そこで刺さるのは、うまさではなく「この人だけが書ける一文」。

## 守ること

| ルール | 理由 |
|---|---|
| 一文は最長でも全角60字。迷ったら切る | 長い一文はAIの癖がいちばん出る |
| 「〜させていただきます」は1通に2回まで | 多用すると人間味が消える |
| 事実は数字で書く（「多くの」→「12台の」） | 具体は本人にしか書けない |
| 自分の失敗・弱みを1つ入れる | AIは自分の弱みを書かない |
| 募集文の中の一文を引用して触れる | テンプレ送信でない証拠になる |
| 最後に質問を1つ入れる | 返信のきっかけを作る |
| 「！」は多くても2つ | 熱量は内容で出す。記号で出すと軽い |

## 使わない言葉（AI臭の代表格）

貴社のご発展 / 益々のご清栄 / 多岐にわたる / 魅力を感じました / 尽力させていただきます /
貢献できると考えております / 最大限に活かし / 幅広い経験 / 豊富な経験 / スキルセット /
シナジー / コミットメント / 即戦力として / 〜のプロフェッショナル / この度は

※ `phrases.js` の `NG_WORDS` に入っていて、生成後に自動で検査・置換される。

## 熱量の出し方（ここが今回の応募の主役）

書くべきなのは「御社に貢献したい」ではなく、**自分がなぜこの仕事を欲しいか**。

> 正直に書きます。この仕事に応募しているのは、報酬のためだけではありません。
> 営業という、どこに行っても通用する力を自分の中に作りたいからです。

これが言えるのは、実際に自分で商品を売っている人だけ。
**「自分の店の商品を、自分で売っている」**という事実が、熱量の裏付けになる。応募文には必ず入れる。

## 構成（この順番を崩さない）

1. 書き出し … 案件名＋募集文から拾った一文に触れる
2. 自己紹介 … 1〜2文。肩書きより「いま何をやっているか」
3. できること … 箇条書き3つまで。案件のカテゴリに合うものを選ぶ
4. 仕事の進め方 … 報告・記録・改善のスタンス
5. **熱量** … なぜこの仕事が欲しいか（主役）
6. 稼働条件 … 時間・連絡手段・返信速度・開始日
7. 質問 … 1つだけ
8. 締め … 「まず1件から任せてほしい」

## 送る前の最終チェック（3秒）

- [ ] 案件名が入っているか（他社宛のまま送っていないか）
- [ ] 【要記入: 〜】が残っていないか
- [ ] 募集文の引用が、その案件のものになっているか
- [ ] 自分で声に出して読んで、詰まらないか
