# 営業応募オートパイロット

営業代行の案件を **探す → 選ぶ → 応募文を書く → フォームに入れる** まで自動でやるツール。
**送信ボタンだけ、自分で押します。** そこだけは自動化しません（誤爆すると取り返しがつかないため）。

```
   ①案件を集める      ②点数を付ける       ③応募文を作る        ④フォームに入れる     ⑤送信
  ─────────────    ─────────────     ─────────────      ─────────────      ───────
   拡張機能が一覧を    地雷案件を弾いて     琴音さんの言葉だけで   氏名・メール・本文を    ← ここだけ人間
   まとめて読み取る    おすすめ順に並べる    組み立てる（AI感なし）  自動入力して送信ボタンを光らせる
```

---

## 中身は2つ

| | 何をするもの | どこで使う |
|---|---|---|
| **Chrome拡張機能** `extension/` | 案件の読み取り・点数付け・応募文作成・フォーム自動入力 | ブラウザ（ランサーズ／クラウドワークス／ココナラ、その他のサイトも手動起動で対応） |
| **コマンド版** `cli.mjs` | 応募文をまとめて作る・点数順に並べる・AI臭チェック | パソコンのターミナル |

どちらも**同じ頭脳（`extension/core/`）**を使っているので、出てくる文章は同じです。

## 準備（最初の1回だけ・10分）

### 1. 自分の情報を書く

`profile/profile.json` を開いて、`?` になっている所を埋める。
何が空いているかは、このコマンドで一覧できます。

```bash
node tools/sales-apply/cli.mjs doctor
```

連絡先など**GitHubに載せたくない情報**は別ファイルに置きます。

```bash
cp tools/sales-apply/profile/private.example.json tools/sales-apply/profile/private.json
# → private.json を編集（.gitignore済みなのでGitHubには上がりません）
```

### 2. Chrome拡張機能を入れる

1. Chromeで `chrome://extensions` を開く
2. 右上の **「デベロッパーモード」をオン**
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. このフォルダの `tools/sales-apply/extension` を選ぶ
5. ツールバーに出たアイコンをクリック → **「設定」** → 自分の情報を入力して **保存**
   （`profile.json` の中身をコピーして「上級者向け」のJSON欄に貼り付けてもOK）

> 設定画面の一番下に「サンプル案件で試しに書いてみる」があります。
> **まずここで一度、自分の応募文を読んでみてください。** 違和感がある言い回しは、その場で直せます。

## 毎日の使い方（1案件あたり2分）

### ① 案件を集める

拡張機能アイコン → **「案件を探しに行く」**
→ 各媒体の検索ページがタブで開く
→ それぞれのタブで、画面右下のパネルの **「① 案件を集める」** を押す

読み取った案件は自動で採点され、**点数順**に並びます。危険な案件（初期費用を取る・情報商材・LINEに誘導して詳細を出す等）は⚠マーク付きで下に落ちます。

### ② 応募する案件を開く

拡張機能アイコンを押すと「応募推奨」の一覧が出ます。上から順に開くだけでOK。

### ③ 応募文を作る

案件の詳細ページで、右下パネルの **「② 応募文を作る」**。
- 案件の種類（テレアポ／商談／フォーム営業／リスト作成…）を自動で判定して、型を変えます
- 募集文の中から**熱のある一文を拾って**、書き出しで触れます（テンプレ送信でない証拠になる）
- 文面はその場で直せます。直した内容は保存されます
- 気に入らなければ **「別の言い回しで」** で作り直せます

### ④ フォームに入れる

**「応募ページへ」** → 応募フォームで **「③ フォームに入れる」**。
本文・氏名・メール・電話・希望金額・稼働時間が自動で入り、**送信ボタンがオレンジで光ります**。

### ⑤ 読んでから、自分で送信

声に出して一度読む。引っかかったら直す。それから押す。
送ったら **「応募済みにする」** を押しておくと、二重応募を防げます。

## コマンド版

```bash
# プロフィールの埋まり具合をチェック
node tools/sales-apply/cli.mjs doctor

# 1件だけ手で作る
node tools/sales-apply/cli.mjs draft --title "案件名" --desc "募集文をそのまま貼る" --print

# 拡張機能から書き出したCSVをまとめて応募文にする
node tools/sales-apply/cli.mjs draft --jobs ~/Downloads/営業案件_2026-08-22.csv --limit 10

# 点数順に並べて、応募する順番を決める
node tools/sales-apply/cli.mjs rank --jobs ~/Downloads/営業案件_2026-08-22.csv

# 自分で書いた文章のAI臭を検査する
node tools/sales-apply/cli.mjs check drafts/2026-08-22_lancers_xxx.md
```

作った応募文は `drafts/` に日付付きで残ります（GitHubには上げません）。

## 文章の質はどこで決まるか

**AIに書かせていません。** `extension/core/phrases.js` に入っている
「琴音さんの言い回し」だけを、案件に合わせて組み替えています。だからAI特有の言い回しが出ません。

文体を変えたいときは:

| 変えたいこと | 直すファイル |
|---|---|
| 言い回し・熱量の出し方 | `extension/core/phrases.js` |
| 文体のルール（守るべき決まり） | `profile/voice.md` |
| 実績の書き方 | `profile/profile.json` の `achievements` |
| 案件の点数の付け方 | `extension/core/scoring.js` |

生成後には必ず**AI臭チェック**が走ります（`貴社のご発展` `尽力させていただきます` `スキルセット` などを検出して置換・警告）。

## 対応していない媒体で使うには

拡張機能アイコン → **「このページで起動」**。
汎用モードでページを読み取って、同じことができます（読み取り精度は下がります）。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「案件が見つかりませんでした」 | ページの読み込みが終わってから押す。それでもダメなら媒体のHTMLが変わった可能性 → `extension/content/adapters/` のヒントを更新 |
| 応募文に `【要記入: ○○】` が残る | `cli.mjs doctor` で未記入を確認して埋める |
| 入力欄に入らない | 「コピー」を押して手で貼る（フォームの作りが特殊な場合の逃げ道） |
| 二重応募が心配 | 送信後に必ず「応募済みにする」を押す |

## やらないと決めていること

- **送信の自動化**（誤送信が取り返しつかない。最後の確認は人間の仕事）
- **同じ文面の一斉送信**（各媒体の規約違反になりうる。案件ごとに文面を変える設計にしている）
- **事実の捏造**（`profile.json` に書いた事実しか応募文に出てきません）
