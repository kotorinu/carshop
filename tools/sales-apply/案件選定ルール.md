| 条件 | 推奨 ◯ | 避ける × |
|---|---|---|
| 営業対象 | **BtoC（個人向け）** | BtoB（法人向け）※原則 |
| 商材の種類 | **無形（サービス・情報）** | 有形（モノ） |
| 商材単価 | **30万〜120万円** | 10万円以下 |

| 媒体 | 扱い |
|---|---|
| 複業クラウド（Another works） | ◯ 使う |
| ランサーズ | ◯ 使う |
| Indeed | ◯ 使う |
| X（旧Twitter） | △ 使えるが**勧誘リスクあり**。うまい話は即断せず運営に相談 |
| Threads | △ 同上 |
| **クラウドワークス** | 🚫 **使用禁止**。実践活動に合う案件がほとんど無く、時間の機会損失になる |

検索キーワードは「営業代行」だけだと有形商材が大量に出る。組み合わせて使う:

```
無形商材 営業代行 ／ オンライン完結 営業代行 業務委託 ／ BtoC 営業代行 サービス
営業代行 未経験可 ／ 営業代行 業務委託 未経験 ／ 営業代行 プラットフォーム
```

**「どの媒体で探せばいいですか」と答えを求めない。「どうやったら良い案件を見つけられるか」で動く。探す期間そのものが実践活動。**

## 各ルールの理由（応募文・面接で自分の言葉として使える）

### BtoCを軸にする
BtoBは相手企業の担当者が**日中**に動く。日中に本業がある人は物理的に対応できない。
BtoCは**夜間でも営業活動ができる**ので副業として成立する。

例外的にBtoB可: ①本業を退職して日中に時間が取れる ②飲食店向けテレアポなど夜間対応できる業種。

> 琴音さんは日中に本業があるため、**BtoBは原則NG**。

### 無形商材を選ぶ
1. **有形は単価が安すぎる**（洋服・飲食物・家電など数万円）。営業よりマーケ・集客の仕組みで売るほうが効率が良く、対面営業の出番が少ない
2. **現場に行く必要が出る**（車・時計・不動産などの高額有形商材は実物を見せる場面がある）

良い無形商材の例: **ビジネススクール／フィットネスジム／英会話スクール／結婚相談所**

### 単価30万〜120万円
10万円以下だと1件成約しても報酬が2,000〜3,000円にしかならないことがある。
同じ労力なら**成約時に数万円**になる案件のほうがプラス。
※ 10万円前後でも経験目的なら問題ない。**まず案件を獲得することを優先**。

### アポイント譲渡型を軸にする
自己獲得型は、SNSや交流会で自分でアポを取る必要がある。取れないと商談自体ができず、
**営業スキルを磨く以前の段階で時間と労力が消耗する**。今の段階では難易度が高すぎる。

譲渡型は会社が広告・SNS・リストで問い合わせを集めてアポを渡してくれる。
**商談・クロージングの実践に集中でき、フィードバックを受けやすい。**

集客方法の優先度（面接で必ず聞く）:

| 優先度 | 集客方法 | 特徴 |
|---|---|---|
| **高** | 広告運用・SNS運用からの問い合わせ | 安定してアポが供給されやすい |
| 中 | LINEリストへの配信からの問い合わせ | 比較的安定 |
| 低 | クラウドワークス等の案件募集経由 | アポの量がまちまち |

> 逆質問: **「アポイントはどのような方法で獲得されていますか？」**
> 案件の質を見極める材料になり、複数案件を抱えたときの優先順位の判断基準にもなる。

### 子ども・学生向けを狙わない
保護者への説明や教育的配慮が必要で難易度が大幅に上がる。
**狙って探すのはNG。取れた案件にたまたま含まれるのはOK。**

### テレアポだけを狙わない
軸は**Zoom等のオンライン相談で完結する案件**。
**テレアポのみの案件を狙って探すのはNG。業務内容に一部含まれるのはOK。**

## 応募の姿勢

- **「経験者優遇」「経験者歓迎」でも積極的に応募する。** ほとんどの案件が経験者募集で出ているが、未経験でも獲得は十分可能。「未経験だから無理」ではなく「未経験でもどうすれば採用してもらえるか」を考える
- **複数案件に同時並行で応募するのが前提。** 1件応募して返信を待つのはNG。数日返信がなければ次へ切り替える
- **完璧な案件を見つけてから応募するのではなく、まず動く**
- 応募数を増やしながら応募文を改善していくのが自走の基本姿勢

## 面接で準備しておくこと

1. 自己紹介（簡単な経歴・現在の状況）
2. 稼働可能な時間帯・週の稼働時間
3. 営業代行に取り組もうと思った動機
4. 通信環境（Zoom等が問題なく使えるか）
5. 逆質問「アポイントはどのような方法で獲得されていますか？」

## ⚠️ 勧誘されたら

案件先や知り合ったクライアントから「うちのスクールに入らないか」「別の組織で一緒に活動しないか」と
誘われたら、**その場で判断せず必ず運営に報告・相談する**。
SNS経由の案件探しでは特に多い。自分一人で判断しない。

## 動き出しの手順

1. 複業クラウド・ランサーズ・Indeed に登録する（**クラウドワークスは使わない**）
2. 「営業代行」「BtoC」「未経験可」などのキーワードで検索する
3. 推奨条件（無形・アポ譲渡型・オンライン完結）に合う案件を見つけたら、**とにかく応募する**
4. 応募しながら、他の媒体や検索キーワードも試してリサーチを広げる
