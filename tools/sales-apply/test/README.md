# テスト

**ZIPを作って渡す前に、必ずここを両方通すこと。**
実際にChromiumへ拡張機能を読み込んで、案件探し〜フォーム入力まで一通り動かす。

```bash
npm run apply:test        # 単体テスト（採点・応募文・HTML読み取り）… 約130項目
npm run apply:test:e2e    # 通しテスト（本物のChromium＋拡張機能）… 約60項目
```

通しテストには Playwright が必要:

```bash
npm i -D playwright jsdom
CHROME_PATH=/path/to/chrome npm run apply:test:e2e   # Chromeの場所を指定する場合
```

## 何をテストしているか

| ファイル | 内容 |
|---|---|
| `unit.mjs` | 6つのチェック項目の◯×不明、危険案件、禁止媒体、マスト条件、金額の読み取り、打ち消し表現、応募文（全9カテゴリ）、AI臭チェック、一覧・詳細のHTML読み取り |
| `run.mjs` | 拡張機能の起動、ポップアップ、巡回、詳細取得、マスト判定（12案件）、合格だけタブで開く、応募文生成、フォーム自動入力、**送信ボタンを押していないこと**、応募済み記録、設定変更の反映、二重収集の防止、設定画面 |
| `fixtures/` | 実物そっくりのテスト求人サイト。12案件が全ルールを網羅している |

## これまでに見つけた不具合（再発防止のため残している）

| 症状 | 原因 |
|---|---|
| 「巡回を始めています…」で固まる | サービスワーカーで動的import（禁止）を使っていた |
| 一覧の全案件が1件目と同じ内容になる | カードの切り出しを文字数だけで判断していて、情報の少ないカードのとき一覧全体を掴んでいた |
| 「新規開拓は一切ありません」を自己獲得型と誤判定 | 打ち消し表現を読んでいなかった／その後、打ち消し除去とアポ譲渡型の検出がぶつかっていた |
| メール・電話・住所がフォームに入らない | 配布用ZIPとリポジトリで同梱プロフィールが違っていた（`build.mjs` に一本化して解消） |
| 詳細URLのidにポート番号を拾う | URL全体から数字を取っていた |
