# 教えてほしいこと（応募文とフォーム自動入力に必要な情報）

答えてもらったら、こちらで `profile/profile.json` と `profile/private.json` に書き込んで**覚えておきます**。
以降ずっとこのファイルが正本になるので、変わったら言ってください。

**優先度A** を答えてもらえれば、その日から応募を始められます。B・Cは後追いでOK。

---

## 優先度A ── これが無いと応募文に【要記入】が残る

| # | 質問 | 例 | 入る場所 |
|---|---|---|---|
| A1 | **稼働できる時間帯**は？ | 「平日19〜23時＋土日終日」「平日9〜18時フル」 | `availability.hours` |
| A2 | **連絡手段**は何が一番早い？ | チャットワーク／Slack／LINE／メール／Discord | `availability.contact` |
| A3 | **返信の速さ**はどう書ける？ | 「平日日中は1時間以内、夜も当日中には必ず」 | `availability.responseTime` |
| A4 | **いつから稼働できる**？ | 「即日」「9月1日から」 | `availability.startDate` |
| A5 | **報酬の下限**は？（これを下回る案件は自動で減点します） | 「時給1,200円」「月3万円」「最初は実績優先で下限なし」 | `minReward` |
| A6 | 応募時の**表示名**は「緒方 琴音」でいい？ 本名フルネーム・フリガナも教えてください | フォームの氏名欄に自動入力します | `displayName` / `fullName` / `fullNameKana` |

## 優先度B ── フォームを完全自動入力するために必要

| # | 質問 | 備考 |
|---|---|---|
| B1 | **メールアドレス**（応募用に使うもの） | `koto.tama.yellow@gmail.com` でいい？ 営業用に分ける？ |
| B2 | **電話番号** | 電話番号必須のフォーム用 |
| B3 | **郵便番号・住所** | 「大阪府◯◯市…」まで。番地は入れる／入れない どちらでも |
| B4 | **インボイス登録番号**の有無 | 無ければ「なし」でOK（聞かれる案件がある） |
| B5 | **開業届／屋号**は出している？ | 個人事業主か、会社員の副業か で書き方が変わります |

> B1〜B3は `private.json`（GitHubに上げないファイル）に入れます。**銀行口座はツールには入れません**——各媒体の管理画面で直接登録してください。

## 優先度C ── 応募文の説得力が跳ね上がるところ

| # | 質問 | なぜ聞くか |
|---|---|---|
| C1 | **営業の経験**は？ 未経験ならそう書きます | 「テレアポは未経験。ただし店頭接客は◯年」のように、正直に書いたほうが通ります |
| C2 | 中古車店の集客以外で、**人に売った経験**は？ | 「自分の商品を自分で売っている」は応募文の一番の武器です |
| C3 | **今の立場**は？（会社員の副業／個人事業主／法人代表） | 稼働時間の説明と、確定申告まわりの案件条件に関わります |
| C4 | **やりたくない商材**はある？ | 投資・情報商材・ネットワークビジネスは既に自動で弾いています。他にあれば追加します |
| C5 | **顔出し／実名公開**はOK？ | プロフィール写真ありのほうが返信率が上がります |
| C6 | 使えるツール（Zoom・Chatwork・Slack・Notion・スプレッドシート…） | 案件の必須条件に書かれていることが多い |

## 優先度D ── 媒体の準備状況（ここが未完だと応募できない）

| # | 質問 |
|---|---|
| D1 | **ランサーズ**のアカウントはある？ 本人確認は済んでいる？ |
| D2 | **クラウドワークス**は？ |
| D3 | **ココナラ**は？ |
| D4 | 他に使う予定の媒体はある？（複業クラウド・Wantedly・SNSのDM営業 など） |

> 本人確認が未完だと、それだけで**書類落ちします**。ここは最優先で埋めてください。
> 未対応の媒体でも、拡張機能の「このページで起動」で同じことができます。

## 答え方

このファイルに直接書き込んでもらってもいいですし、チャットで
「A1は平日19時から23時、A2はチャットワーク、…」のように箇条書きで返してもらえれば、
こちらで全部ファイルに反映します。

**全部が埋まっていなくても、A1〜A6だけ答えてもらえればその日から応募できます。**
