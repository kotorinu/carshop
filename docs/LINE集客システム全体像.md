# カーショップJupiterCoring LINE集客システム 全体像

第三者（パートナー・外注・別のAI）への説明用。2026-07-19時点。

## 一言でいうと

**Lステップ（月3万円〜）相当のLINE顧客管理・集客自動化を、オープンソース＋Cloudflare無料枠で月0円運用しているシステム。**
TikTok等のSNS→LINE友だち追加→自動接客→査定/来店予約→成約、までの導線が自動で回る。

## なぜ作ったか

- 中古車販売（株式会社Jupiter Coring 大阪支店・寝屋川）の集客をSNS×LINEに一元化したかった
- Lステップ等のSaaSは月3万円〜で、立ち上げ期には重い
- 過去にエルメ（無料版Lステップ代替）を試したが止まっていた。旧自作bot（Railway・月$5）も文言が古く機能が薄かった

## システム構成

```
TikTok / Instagram / ジモティ / メルカリ / 店頭QR / 紹介
   │  プロフィールに媒体別リンク（?ref=tiktok 等）
   ▼
LINE公式アカウント（カーショップJupiterCoring @777mfasy）
   │  Webhook
   ▼
LINE Harness（オープンソースCRM）on Cloudflare Workers ←月0円
   ├─ D1データベース（顧客・タグ・配信履歴）
   ├─ R2ストレージ（画像）
   ├─ cron 5分毎（ステップ配信・予約配信）
   └─ LIFF（LINE内で開く査定フォーム）
   ▼
外部連携: RESERVA（来店予約・無料）／カーセンサー（在庫詳細）／
kotokoto-company-site.vercel.app（在庫データcars.json）
```

- 本番URL: https://carshop-line-harness.jupitercoring.workers.dev
- 認証情報は `carshop/.env`（git管理外）に集約

## お客様から見た体験

1. **友だち追加した瞬間**: ブランドカード（「クルマ、買うのも売るのも。」）＋3ボタン（車を探している／売りたい／店に行きたい）が届く
2. **ボタンやキーワードに全自動で反応**:
   - 「査定」→ 30秒査定フォーム（LINE内で完結）＋「車種・年式・走行距離を送るだけでもOK」
   - 「在庫」→ 実在庫12台のカルーセル（写真・支払総額・カーセンサー詳細リンク付き。安い順）
   - 「予約」→ RESERVA予約ページへ（空き状況を見てネット予約）
   - その他何を送っても→「営業時間内に必ずお返事します＋電話番号」（無視される人ゼロ）
3. **追加後7日間の自動育成**: Day1在庫紹介→Day3売却のコツ→Day5事例→Day7買取キャンペーン
4. フォーム送信後は確認メッセージが即届く

## 運営側から見た機能

- **行動が全部タグになる**: 流入元（src:tiktok等）・興味（int:査定/int:購入）・状態（st:来店予約/st:成約）→「TikTok経由で査定に興味がある人だけに配信」が可能
- **オーナー通知**: 査定申込み・未対応チャットをPCが15分毎にチェックし、オーナーのLINEに内容付きで通知
- **運用CLI**: `kpi.mjs`（週次KPI）／`broadcast.mjs`（セグメント配信）／`update-inventory.mjs`（在庫カルーセル更新）
- 1:1の個別チャットは従来どおりLINE公式アカウントアプリで
