# note下書き:「中古車屋のLINEを"AI店員"にしたら、24時間働く営業部長ができた話」

（週次発信用ドラフト。公開前に校閲さんに通す。実名の数字は出た分だけ差し替える）

---

## 導入（共感フック）

中古車屋さんの悩みはだいたい同じです。
「カーセンサーから問い合わせは来る。でも夜中に来たメッセージに朝返したら、もう他の店で決まってた」。
中古車は"最初に返事をした店"が勝つ商売。なら、返事を機械に任せればいい——そう思って、大阪・寝屋川の中古車店のLINEをまるごとAI化しました。

## 作ったもの（スクショ差し込み）

1. **友だち追加した瞬間、実車写真つきのカードが届く**（在庫・査定・来店予約の3ボタン）
2. **「在庫をみる」→ カーセンサーと自動連動した在庫カルーセル**。売約された車は勝手に消える
3. **来店予約は「今週土曜 午前」をタップするだけ**。店主のLINEに即通知が飛ぶ
4. **TikTok用の縦動画も自動生成**。掲載写真を置いてコマンド1発、字幕・価格演出・LINE誘導つき
5. **毎朝8時、AIが数字をチェック**：新入庫・売約・値下げを検知して、返信漏れまで列挙

## 技術の裏側（さらっと・詳細は問い合わせ誘導）

- LINE Messaging API + Flex Message、ホスティングはRailway（月800円くらい）
- 在庫はカーセンサー掲載データと同期したJSONをライブ参照（更新作業ゼロ）
- 動画はHTML/CSSベースのレンダリングパイプライン（GPU不要、1本40秒で生成）
- 全部で使ったお金：サーバー代のみ。広告費ゼロ

## 学び（ここが本文の価値）

- **自動化すべきは「返信の速さ」であって「接客のすべて」ではない**。AIは一次対応と受付だけ。クロージングは人間がやるから信頼される
- **完全自動投稿はやらない**。TikTokの自動投稿はBANリスク。線引きの設計こそがプロの仕事
- **数字の管理まで自動化して初めて「仕組み」になる**。作って終わりのbotは3週間で死ぬ

## 締め（CTA）

この仕組み、実は中古車屋さんに限らず「問い合わせ→来店」で商売しているお店なら全部同じ型で作れます（美容室・工務店・買取店・整体…）。
「うちの店でもできる？」という方は、プロフィールのリンクからどうぞ。あなたのお店の商品で**デモを1本無料で作って**お見せします。
