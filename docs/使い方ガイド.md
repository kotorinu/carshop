# カーショップLINE・動画ツール 使い方ガイド（初心者向け）

むずかしい操作はぜんぶ自動化してあるので、**人間がやることは3つだけ**です。

---

## 1. お客様からLINEが来たら（いちばん大事！）

**botが最初の応答は自動でやってくれます。** 人間の出番はそのあとです。

- お客様がメニューを押す → 在庫カード・査定案内・予約受付は**全部自動**
- お客様が「来店希望: 今週土曜の午前」を送る → botが「承りました、本日中に確定連絡します」と自動返信
- **人間がやること**: [LINE公式アカウントアプリ](https://manager.line.biz)（スマホアプリ「LINE公式アカウント」）を開いて、**30分以内に確定の返事をする**

> 💡 なぜ30分？ 中古車は「最初に返事をくれた店」で決まるからです。
> 返事の型: 「◯◯様、土曜午前でご用意できます！10時と11時どちらがよいですか？」
> （必ず**二択**で聞く。これだけで来店率が変わります）

## 2. 在庫が変わったら（入庫・売約）

Claude（このチャット）に、こう言うだけ：

- 「**プリウス売れたから消して**」→ LINEの在庫カードから消えます
- 「**カーセンサーに新しい車載せたから同期して**」→ 写真ごと取り込んでLINEに反映

自分でやりたい場合（PCで carshop フォルダを開いて）:
```
npm run sync:inventory          ← 実在庫の一覧を見る
npm run sync:inventory -- プリウス  ← 車種名で取り込み
```

## 3. TikTok動画を作りたくなったら

Claudeに「**◯◯（車種名）の動画作って**」と言うだけ。
できあがった動画は `content/renders/` にMP4で入っています。

**投稿のやりかた**（1本2分）:
1. MP4をスマホに送る（LINEの自分専用トークに送るのが楽）
2. TikTokアプリで「＋」→ その動画を選ぶ
3. **音楽は流行ってる曲をアプリの中で付ける**（これが伸びるコツ。動画には音をわざと入れてません）
4. キャプションとハッシュタグはClaudeが動画と一緒に出してくれるのでコピペ

## こまったとき

| こまりごと | どうする |
|---|---|
| botが返事しない | Claudeに「LINE botの調子見て」と言う |
| あいさつが2回届く | LINE公式アカウント設定→応答設定→「あいさつメッセージ」をOFF |
| リッチメニューの文言を変えたい | Claudeに「リッチメニューの◯◯を△△に変えて」 |
| 在庫カードの並び順・内容を変えたい | Claudeに言えばOK |
| 予約の通知を自分のLINEに欲しい | Claudeに「オーナー通知を設定して」と言う（あなたのLINE IDを1回登録するだけ） |

## しくみ（ざっくり）

```
TikTok動画 → 見た人がLINE友だち追加 → リッチメニューで在庫/査定/予約
→ botが受付 → あなたに通知 → 30分以内に返事 → 来店 → 成約🎉
```

- botは **Railway** というサービスで24時間動いています（月5ドルくらい）
- お金まわり・値下げ判断・出品文はぜんぶClaudeの「car-sales-marketing」が判断できます。
  「この車売れない」「今週の数字これ」とチャットに送るだけでOK
