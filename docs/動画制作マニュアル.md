# 動画制作マニュアル（TikTok / Instagramリール共通）

最終更新: 2026-07-19。**動画の仕事はただ1つ「LINE登録させること」。** バズは手段、成約が目的。

## 毎日の回し方（考えることゼロ）

Claudeに「**今日の分**」と言う → 以下がフルパックで納品される:
- 今日のピックアップ車1台（車検切れが近い順・ローテーション）＋ターゲット明記
- 撮影台本 or 写真選定指示 ＋ テロップ文 ＋ 投稿文（TikTok/リール/X）＋ 投稿時間
- 人間タスクは**1日8〜15分**に収まる粒度

## ⚠️ 前提: 手元にあるのは写真だけ（現地で車に触れない）

車両情報はcars.json（カーセンサー由来の写真）のみで届く運用のため、**傷を接写する・現地で撮影する、は基本できない**。
「傷まで全部見せます」と謳って実際には見せられないと、来店時に信用を落とす。
→ **写真スライドショーを主戦力にし、「写真で分からない部分は現車確認へ」で正直に誘導する**のが正解。現地で実車を見る機会があるときだけ、下の「実写ボーナス版」を使う。

## 2つの製造ライン

| | A: 写真スライドショー（**基本はこれ**） | B: スマホ実写（現地に行けるときだけ） |
|---|---|---|
| 作り方 | cars.jsonの写真6〜10枚→「車両動画メーカー.html」でズーム/スライド生成 | 6カット・撮影3分のレシピ台本どおり |
| 強み | 毎日出せる・現地不要・品質が安定 | 信頼が一番強い（実在確認になる） |
| 使い分け | **毎日のデフォルト** | 納車・仕入時など現地に行けた日だけ |

## Aライン: 写真スライドショー台本（基本レシピ・8枚構成）

1. **フック（1.5秒・最重要）**: 価格・地域・用途を数字で。「大阪で総額30万円台の軽自動車」
2. 車種名（1.5秒）: 「ダイハツ タント」
3. 走行距離（1.5秒）: 「走行9.9万km」
4. 車検（1.5秒）: 「車検2027年1月まで」
5. 強み写真1枚（2秒）: 後部座席 or 荷室など、写真から伝わる利点
6. 支払総額（2秒・大きく）: 「総額22.8万円」
7. **正直な一言（2秒・信頼の要）**: 「写真では分からない部分もあるため、現車確認をおすすめしています」← 隠さない姿勢はここで出す。嘘の「傷まで見せます」より効果的
8. **CTA（2秒・固定文言）**: 「在庫確認・来店予約・無料査定はプロフィールのLINEから」

テロップは各写真に1メッセージだけ乗せる（車種名・数字・結論）。BGMはテンポの良い曲、切り替えは1枚1〜2秒でリズムよく。
**同じ写真を1本の動画で2回使わない**（8枚構成なら8枚別の写真。足りなければ枚数を減らして1枚の表示を長くする）。
写真に**ゆっくりズームイン/スライド（Ken Burns効果）**をかけて「動き」を出す。CapCutなら写真選択→「アニメーション」→ズームで1タップ。静止画の紙芝居とは滞在時間が段違い。

## Bライン: 実写ボーナス版（現地に行けた日限定・6カット）

1. **フック（1.5秒）**: 「支払総額22万のタント、車体をぐるっと見せます」
2. 外観ぐるり（正面→斜め45度・3歩歩く・5秒）
3. **見えている傷・弱点があれば接写（3秒）**: 「ここに傷あります。だからこの値段」← 現地で実際に確認できた時だけ言う。写真だけの時にBラインの真似はしない
4. 内装（運転席に座って一周・5秒）
5. 強み1つだけ（車検残・装備・燃費のどれか1つ・4秒）
6. **CTA（3秒・固定文言）**: 「詳しくはプロフィールのLINEから。査定も30秒でできます」

## 品質担保チェックリスト（投稿前に全部YESか確認）

**内容**
- [ ] 最初の1.5秒に数字（価格・年式・走行）か意外性があるか
- [ ] 写真から分かる範囲の特徴・弱点は正直に書いたか（見えていないものを「見せます」と嘘をつかない）
- [ ] Aラインの動画には「写真では分からない部分もあるため現車確認をおすすめしています」を入れたか
- [ ] 支払総額で言っているか（車両本体価格で釣らない）
- [ ] CTAで「プロフィールのLINE」に誘導したか
- [ ] 15〜25秒に収まっているか（長い=離脱）

**見た目**
- [ ] 縦動画（9:16）・明るい時間帯の屋外か
- [ ] テロップは**太丸ゴシック・白文字・フチどり**で統一（多色バラ撒き禁止・アクセント1色まで）
- [ ] テロップは画面下1/3・2行以内・1画面1メッセージ
- [ ] 音量: セリフがBGMより大きいか

**投稿**
- [ ] キャプション1行目に価格 or ベネフィット
- [ ] ハッシュタグ: 地域（#大阪中古車 #寝屋川）＋車種＋悩み系 = TikTok5個/リール8個
- [ ] 投稿時間はターゲットに合わせたか（職人19-21時・子育て21-22時・通勤7-8時/20時台）
- [ ] TikTokとリールに同じ動画を出してOK（透かしロゴ無し版を使う）

## NG集（1つでもやったら品質不合格）

- 見ていない傷・状態を「見せます」「確認済み」と断言する（写真だけの時の最大の地雷。来店時の信用失墜に直結）
- 走行距離・車検・価格をぼかす／映さない（分かっている情報は必ず出す）
- 「詳細はコメント欄」（コメントに埋もれる。誘導は必ずプロフィールLINEへ）
- 前置き挨拶（「こんにちは〜」で始まる動画は0.5秒でスワイプされる）
- 多色テロップ・派手なエフェクト盛り（統一感が信頼をつくる）
- 車と関係ないトレンドネタへの便乗

## SNSプロフィール設定（1回だけ・今日やる）

### TikTok: 自己紹介文とリンクを両立させる方法

TikTokは**フォロワー1,000人未満だと「ウェブサイトリンク」の専用欄が出ず**、自己紹介欄（80文字）に直接URLを貼るしかない。トラッキングURL（68文字）だけで80文字中68文字を使い切り、説明文が入らないのはこれが原因。

**解決策（無料・2分）**: 設定 →「アカウントを管理」→「**ビジネスアカウントに切り替え**」。フォロワー数に関係なく、切り替えた瞬間に自己紹介とは別の「ウェブサイト」欄が使えるようになる。

切り替え後の設定:
- 自己紹介（80文字）: `大阪・寝屋川の中古車販売店🚗\n無理な営業なし。分かる範囲は正直にご案内\n在庫確認・来店予約はLINEから👇`
- ウェブサイト欄: `https://line.jupitercoring.workers.dev/tiktok`（短縮版・計測付き）
- **ビジネスアカウント切替で証明書等を求められて進めない間の繋ぎ**: 自己紹介80文字にこう入れる→ `寝屋川の中古車店🚗査定・在庫はLINEで👇\nline.jupitercoring.workers.dev/tiktok`（52文字・収まる）。bioのURLはタップできないが、短いので手打ち・コピーができる。並行して動画内＋コメント固定で誘導

「傷も弱点も正直に言う」は現地で車を確認できていない今は使わない（NG集参照）。「分かる範囲は正直に」が実態に合った誠実な表現。

### Instagram: そもそも問題なし

Instagramはフォロワー数に関係なく、プロフィール文（150文字）とリンク欄が最初から別々にある。直貼りでOK。
- プロフィール文: `大阪・寝屋川の中古車販売店🚗\n無理な営業なし。分かる範囲は正直にご案内\n在庫確認・来店予約・無料査定はLINEから👇`
- リンク: `https://carshop-line-harness.jupitercoring.workers.dev/auth/line?ref=instagram`
- （余力があれば）プロフィール文の下にリンクが表示されるとき、タイトルを「🚗 在庫を見る・30秒査定はLINEで」に編集すると生URLが隠れて見た目が整う

### 固定動画3本（プロフィール上部に固定・両媒体共通）

1. 「初めての方へ｜大阪・寝屋川の中古車販売店です」（自己紹介・信頼構築）
2. 「今の在庫まとめ｜総額○万円から」（一覧性）
3. 「購入・来店・査定の流れ」（行動の壁を下げる）

## 第三者の声（納車事例）の作り方

成約のたびに以下をルーティン化（Claudeに「◯◯売れた」と言えばリマインドされる）:
1. 納車時に**車と一緒に写真1枚**（顔出しNGなら車＋手だけ・後ろ姿でOK）
2. 一言もらう「どこが決め手でした？」
3. 使い道は三毛作: ①納車報告動画（社会的証明・一番伸びやすいネタ） ②LINEのDay5配信素材 ③Googleビジネスプロフィールの口コミ依頼（その場でQR渡す）
