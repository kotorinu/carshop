# 中古車TikTokバズ研究（2026年7月調査）

> このドキュメントは実際のWeb調査に基づく。`content/brand/tiktok-spec.md` の改訂根拠。
> 定期的に（月1目安）再調査して更新すること。

## 1. 2026年アルゴリズムの要点

| 項目 | 数値・事実 | 制作への示唆 |
|---|---|---|
| 有効視聴（クオリファイド・ビュー） | **5秒以上**の視聴でカウント | 最初の5秒に全力投球。5秒までに「見る理由」を確定させる |
| バズの完視聴率ライン | 従来50% → **約70%に上昇** | 長い動画ほど完走が難しい。**15〜30秒**で確実に完走させる |
| 最適な長さ | **15〜30秒のハイブリッド尺**が2026年の主流 | 在庫紹介=15〜20秒、買取ノウハウ=20〜30秒 |
| フォロワーファーストテスト | 投稿直後、まず既存フォロワー小グループに配信して反応を評価 | 初速が命。投稿後30分のコメント返信・エンゲージ運用が効く |
| いいねの重み | ほぼ無力。完了率・リピート・シェアが主要因 | 「いいね誘導」より「最後まで見せる構成」に投資 |

## 2. 車販売店で実際に効いているコンテンツ型（調査結果）

### 効果実証済みの型（優先度順）

1. **ウォークアラウンド車両紹介（最強・在庫系の主軸）**
   - 15秒で1台の「特徴＋価格アンカリング」を見せる型。米調査では自動車TikTokで最も成約に繋がる形式。視聴者はスクリーンショットを撮って問い合わせる
   - 事例: 中古車店が15秒の車両紹介動画で**月間販売台数30%増**
   - 構成: 外観ヒーロー → 特徴2〜3個をテンポよく → 価格ドン → CTA
2. **正直・透明性コンテンツ（買取系・信頼の核）**
   - 「査定の裏側」「維持費の本音」「この車の弱点も言う」— 騙されたくない買い手・売り手に刺さり、シェアされやすい
3. **豆知識・ハウツー**
   - 「タイヤの製造年の見方」「キーレス電池交換」など保存されやすい。保存=アルゴリズム高評価
4. **納車の瞬間**
   - 感情が動く。ブランド好感度向上
5. **舞台裏・スタッフの人柄**
   - 「車屋=怖い」の先入観を壊す

### 数字で語る事例
- 関西の中規模ディーラー: ハッシュタグ戦略で月間視聴100万回、**来店35%増**
- 週3回の15秒車両紹介の定期投稿が有効パターンとして確立
- TikTok経由はFacebook比で広告費が低く、インプレッション・エンゲージメントが高い（Toyota事例: CPA38%減）

## 3. バズるフックの型（0〜3秒・2026年版）

調査で確認された5大パターン＋既存spec併用:

1. **衝撃の事実型**: 「中古車の90%は高く売れるのに損してる」「〇〇を知らないだけで50万損」
2. **疑問提起型**: 「あなたの車、本当の価値知ってますか？」
3. **ビフォーアフター型**: 結果を最初に見せる（「38万→75万になった査定」）
4. **意外性型**: 常識を覆す（「走行10万kmは"買い"です」）
5. **共感型**: あるある（「車売るとき、これ全員やりがち」）

- 禁止: 「どうも」「今日は」等の挨拶入り（2秒で7割離脱）
- **フックに数字を入れると強い**（価格・年式・◯◯万円）

## 4. 見せ方・編集の勝ちパターン

- **フルスクリーン縦型の没入感**: 実車を画面いっぱいに。周辺の映り込みを避ける
- **カット割り: 2〜3秒に1回**（従来の3〜5秒より速い。2026年はテンポ最優先）
- **1動画1メッセージ**: 詰め込むと完走率が落ちる
- **テロップはセーフマージン内**（上15%・下25%はTikTok UIと被る）— 見切れは完視聴率を直撃
- **ラスト3秒でCTA**: 「LINEで査定」「在庫はプロフから」
- 写真スライドショー（パンパン切替だけ）は没入感が出ず不利 → **写真は動画化（AI生成 or Ken-Burns強）して「動いている実車」に見せる**

## 5. このプロジェクトへの適用（spec改訂の要点）

1. 長さを **25〜40秒 → 15〜30秒** に短縮（在庫=15〜20秒、買取=20〜30秒）
2. シーン数 8 → **5〜6**、カット割り2〜4秒
3. 写真は素材プール。**AIがベスト3〜6枚を役割別に選定**（ヒーロー外観/走り/内装/ディテール）し、全部は使わない
4. 全シーン実写（漫画パネル廃止）。Klingで写真→動くクリップ化、無ければ強めKen-Burns
5. 価格アンカリング必須: 上部スペックバー常時＋価格リビール"ドン"
6. フックは数字入り。5大パターンからAIが選択
7. エンドカードは3〜4秒に短縮（長いと完走率が落ちる）
8. 投稿後30分のコメント返信を運用ルーティンに含める（フォロワーファーストテスト対策）
